# Coroner's console

Design source: user-supplied DESIGN_BRIEF.md, read in full. The earlier green dashboard is replaced, not reskinned. The investigation engine remains the source of every outcome.

Palette: Tomb #100D0E, Slab #1A1517, Vault #241C1F, Bone #D9D0BF, Ash #8C8378, Oxblood #7A1F26, Arterial #B3262F, Formalin #8FA79A, Tallow #B8975A. Muted status colours have glyphs and literal verdict words. Oxblood/Arterial are marks, not low-contrast body text.

Type: locally bundled IM Fell English for all interface text, headings and autopsy prose; locally bundled IBM Plex Mono only for hashes, commands, captured output, exits, dates/durations generated by the engine, and diffs. Test Fell at 16px before adding the permitted Newsreader fallback.

Layout: a working console at first paint, no marketing hero, sidebar rail, rounded card grid or decorative orbital graphic.

```text
Time of Death                             Synthetic demo repository
-------------------------------------------------------------------
The case file         The timeline                 The autopsy
Repository            Remaining suspect range      Established
Working revision      [Bayer oxblood field]         Evidence links
Failing revision      good / bad / skip marks       Hypothesis
$ check command       Selected revision             Look next
Begin / Cancel        stdout | stderr               Model controls
Bisect log            Candidate toe tag + diff      Export MD / JSON
-------------------------------------------------------------------
Current phase          Recorded checks              Elapsed / shortcuts
```

Desktop columns 22% / 50% / 28%; below 1024px: case, timeline, evidence, candidate, autopsy. At 375px the revision strip scrolls, output is bounded, and Cancel stays reachable.

Principles:
1. The timeline carries uncertainty, not invented probability. Dither indicates the unresolved interval; cold regions have been eliminated under the engine's stated assumptions. Text describes the same range.
2. Ordered Bayer 8x8 at 2-3 CSS pixels per cell; two palette colours, fixed matrix, no animated noise. Only the timeline sweeps; pause hidden/offscreen, respect reduced motion. Static texture is limited to idle title, toe tag margin and empty-state margins, never under text.
3. Machine output looks machine-produced; interface prose looks like a ledger. No uppercase eyebrows, emoji, arrow-suffixed controls, middle-dot metadata or glow.
4. Established results and model hypotheses use different treatments and explicit labels. No toe tag for an inconclusive case.
5. Preserve utility: keyboard navigation, actual stdout/stderr, line-numbered diffs, persistent synthetic label, exports with completion filenames, and every failure state.

Review against the brief: removed the old rail, green palette, promotional hero, uniform rounded panels, decorative diagram, numbered panel labels and generic metric cards. Bayer rendering is code-native and small; React/Vite are build-time dependencies and bundled fonts are served offline. The supplied YouTube tutorial is being inspected separately; no separate dithering skill exists in the accessible skill catalog.

Verification: real demo, recorded failure states, 1440px and 375px screenshots, no external asset requests, contrast measurements, keyboard and reduced-motion checks. Remove any element that is only decoration during final critique.
